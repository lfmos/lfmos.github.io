01 / SOBRE MIM

Tecnologia com propósito.
Segurança na prática.

Sou graduado em Segurança Cibernética pela Estácio de Sá, técnico em Telecomunicações pelo CEFET/RJ e pós-graduando em Engenharia de Cloud Computing no Instituto Infnet. Minha trajetória conecta redes, desenvolvimento e proteção de ambientes digitais.

Tenho interesse especial em Detection Engineering, Cloud Security e DevSecOps. Construo laboratórios para explorar como sistemas se comportam: da coleta e correlação de eventos de segurança à configuração de containers, políticas de rede e pipelines de validação.

Gosto de transformar aprendizado em entregas verificáveis. Por isso, mantenho repositórios com código, documentação, testes e observações sobre o que foi realmente implementado — inclusive limitações de cada ambiente.

Projetos.

Experimentos práticos para investigar problemas de segurança, construir infraestrutura reproduzível e documentar decisões técnicas. Os projetos autorais têm código disponível; o laboratório OSINT representa uma colaboração em desenvolvimento.

01 / DETECTION ENGINEERING

NexVigil ↗

Laboratório de detecção e validação contínua de segurança. Uma API FastAPI gera eventos sintéticos; um motor em Python processa a telemetria, correlaciona tentativas de autenticação, classifica alertas e mantém estado entre reinicializações. Simulações controladas apoiam a análise Blue/Purple Team, com integração documentada ao Wazuh SIEM.

PythonWazuhMITRE ATT&CK
02 / KUBERNETES SECURITY

K8s Security Lab ↗

Comparação prática entre workloads propositalmente inseguros e versões protegidas em Kubernetes. Aplica execução sem privilégios, filesystem somente leitura, seccomp e NetworkPolicies com Calico. O laboratório foi validado localmente em Minikube, com testes de conectividade e análise dos manifestos pelo Checkov.

KubernetesCheckovCalico

03 / CLOUD & DEVSECOPS

GKE DevSecOps Lab ↗

Projeto de referência para entrega segura com Docker, GitLab CI/CD e Kubernetes: validação, build, publicação de imagem e deploy planejado para GKE. Inclui testes locais e workflow no GitHub Actions, hardening do NGINX e controles para workloads. A execução real em GKE depende de uma conta e integrações GCP configuradas.

Swarm Vagrant Lab ↗

Laboratório distribuído que provisiona quatro máquinas virtuais Ubuntu com Vagrant e VirtualBox, formando um cluster Docker Swarm com um manager e três workers.
