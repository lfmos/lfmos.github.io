Copie os arquivos deste pacote para a raiz do repositório `lfmos/lfmos.github.io`, preservando os arquivos históricos desejados. Atualize o `README.md` e faça commit na branch `main`. O GitHub Pages já vinculado à branch deverá atualizar o site após o processamento.
